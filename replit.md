# Rabindra Biswal - GitHub Profile README

## Overview
This is a GitHub profile README repository that showcases Rabindra Biswal's professional profile as a Senior Staff Engineer and Test Automation Architect. The project has been configured to run as a web application that renders the README.md file as a styled webpage.

## Project Architecture
- **server.js**: Express.js server that reads README.md, converts it to HTML using `marked`, and serves it with a dark-themed styling
- **README.md**: The main profile content with badges, stats, certifications, and contact information

## Tech Stack
- Node.js 20
- Express.js (web server)
- Marked (Markdown to HTML conversion)

## Running the Project
The server runs on port 5000 and serves the README content as a styled HTML page.
